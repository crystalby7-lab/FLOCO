# FLOCO MVP (웹)

친구 2~5명이 고양이 1마리를 함께 키우고, 근거를 쓴 제안에 투표해 모의투자하는 청소년 금융교육 게임의 MVP.
휴대폰에서 앱처럼 보이도록 만든 웹 서비스입니다 (홈 화면에 추가하면 주소창 없이 열림).

## 실행

```bash
npm install
npm run dev      # 개발 서버 (같은 와이파이의 휴대폰에서 보려면: npm run dev -- --host)
npm run build    # 배포용 빌드 → dist/
```

## 구조

| 파일 | 내용 | 기능 |
|---|---|---|
| `src/types.ts` | 데이터 구조 (users·guilds·제안·복기) | 데이터 명세 |
| `src/store.ts` | 게임 상태·규칙·모든 동작 | F4~F9 |
| `src/aiReview.ts` | AI 근거 검토 (임시 규칙) | F4 |
| `src/data/quests.ts` | 퀘스트 콘텐츠 | F1·F2·F3 |
| `src/data/market.ts` | 종목·시세 (데모용 가상 시세) | F5 |
| `src/data/shop.ts` | 상점 아이템 | F9 |
| `src/screens/` | 화면 5개 (홈·지도·투자·상점·길드) + 가입 | |
| `src/components/CatView.tsx` | 고양이 그림 (디자인 외주 후 교체) | F7 |

## 지금 임시로 해둔 것 → Firebase 연결 때 바꿀 것

- **저장**: 브라우저 localStorage → Firestore (`store.ts`의 load/save와 action만 교체)
- **친구**: 데모 친구 2명(하늘·도윤)이 자동 투표·복기 → 실제 초대 링크 가입
- **AI 검토**: `aiReview.ts` 규칙 → 서버 함수에서 위닛 세이프가드 호출 (API 키는 서버 환경변수에만)
- **시세**: 가상 시세 + "하루 지나기" 버튼 → 공공데이터포털 금융위원회 주식시세정보 종가 (하루 1회)
- **보호자 동의**: 아직 없음 (만 14세 미만 방식 결정 필요)

## 규칙 (숫자는 `store.ts`의 RULES에서 조정)

- 레벨은 근거·복기로만 오름: AI 통과 제안 +15, 반대 이유 +5, 복기 +30 (수익과 무관)
- 자동 훈련: 시간당 60G, 8시간치 상한
- 고양이는 배부름·기분이 10 아래로 내려가지 않음 (손실로 죽지 않음)
- 과반 찬성 시 매수, 확률형 뽑기·수익률 순위·투자 유리 아이템 없음
